# Security Policy

## Supported Versions

HELEN is currently pre-release (`0.1.x`). Security fixes are applied to the
latest commit on the `main` branch only.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

To report a vulnerability, open a
[GitHub Security Advisory](https://github.com/dmankv/Project-HELEN/security/advisories/new)
(private disclosure). Include:

1. A description of the vulnerability and its potential impact.
2. Steps to reproduce or a proof-of-concept.
3. Any suggested mitigations you have in mind.

You can expect an initial acknowledgement within **5 business days**. If the
vulnerability is confirmed, a fix will be prioritised and a patched release
will be published as soon as practical. You will be credited in the release
notes unless you prefer to remain anonymous.

If GitHub Security Advisories are not an option, you may contact the
maintainer directly via the email address shown on their GitHub profile.
