🛠️ Local Development Setup

Run HELEN on your machine:

# Clone the repository
git clone https://github.com/jackdeadicay-boop/somthing.git
cd somthing

# Checkout the learning system branch
git checkout ai-learning-system

# Install dependencies
npm install

# Start development server
npm run dev

# Open in browser
http://localhost:3000

📚 How HELEN Works

HELEN processes your requests through a 7-step learning pipeline:

  1. Intent Inference - Analyzes what you're asking
  2. Memory Retrieval - Recalls relevant past interactions
  3. Planning - Creates a strategy for the best response
  4. Candidate Generation - Generates multiple response options
  5. Evaluation - Scores each option for quality
  6. Selection - Chooses the best response
  7. Learning - Stores the outcome and learns from feedback
